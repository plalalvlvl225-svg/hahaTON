# Оптимальный маршрут

Программа на Python 3.15 находит план перевозок с минимальной суммарной стоимостью. Для конкурсного входа 1000 × 1000 минимум равен **1 415 114**, для примера 3 × 4 из условия — **170**. Расчёт использует стандартную библиотеку и NumPy. Оба алгоритма оптимизации реализованы в исходном коде проекта.

## Запуск на Windows 11

Потребуется 64-разрядный Python 3.15. Откройте PowerShell в каталоге репозитория. Один раз создайте окружение и установите зависимость.

```powershell
py -3.15 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

В репозитории уже есть учебный `in.txt`. Для конкурсного расчёта положите свой `in.txt` в рабочий каталог. Выполните команду, после которой в этом же каталоге появится `out.txt`.

```powershell
.\.venv\Scripts\python.exe main.py
```

Время полного запуска на конкретном компьютере можно измерить в PowerShell.

```powershell
(Measure-Command { .\.venv\Scripts\python.exe main.py }).TotalSeconds
```

## Запуск на macOS и Linux

```sh
python3.15 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Если окружение уже активно и NumPy установлен, достаточно `python main.py`. Программа ищет вход и создаёт выход в текущем рабочем каталоге. Это позволяет запускать один экземпляр кода на разных наборах в отдельных папках.

## Формат и пример

В первой строке входа указаны число поставщиков N и число потребителей M. Во второй идут N запасов, в третьей — M потребностей. Следующие N строк образуют матрицу целочисленных тарифов размером N × M. Запасы и потребности неотрицательны, их суммы равны.

```text
3 4
30 40 20
20 30 30 10
2 3 2 4
3 2 5 1
4 3 2 6
```

Первая строка результата содержит точную суммарную стоимость. В следующих N строках записаны объёмы перевозок. У учебного примера получается такой выход.

```text
170
20 0 10 0
0 30 0 10
0 0 20 0
```

## Проверка результата

В активированном окружении выполните команды ниже. Первую можно запускать обычным Python 3.15 со стандартной библиотекой. Вторая запускает тесты проекта.

```sh
python tools/check_plan.py in.txt out.txt
python -m unittest discover -s tests -v
```

Проверяющая программа заново читает оба файла, пересчитывает объёмы и стоимость, восстанавливает двойственные потенциалы и сверяет нижнюю границу с ценой перевозок. На конкурсном файле обе суммы равны 1 415 114. Проверка запускается отдельно от измеряемой программы.

## Как устроено решение

За файловый ввод и вывод отвечает `main.py`. В `transport.py` обрабатываются пустые строки и столбцы, нормализуются тарифы и выбирается метод. В `tight_flow.py` реализован поиск увеличивающих путей по маршрутам с нулевой приведённой стоимостью. В `simplex.py` реализован транспортный симплекс с проверкой тарифов всей таблицы.

Пошаговый расчёт на примере, обоснование выбора алгоритма, доказательства точности, работа с большими числами и результаты замеров собраны в [подробном разборе для защиты](docs/algorithm.md).
