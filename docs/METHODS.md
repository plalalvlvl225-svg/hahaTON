# Три метода на одном примере

Наш метод, метод потенциалов и венгерский метод, посчитанные руками на одной задаче. Все числа проверены программой.

## Пример

```
          B1   B2   B3   есть на складе
A1         3    2    2        3
A2         5    4    3        5
A3         6    4    2        2
нужно      4    2    4
```

Правильный ответ: **32**.

Напоминание из [SIMPLE.md](SIMPLE.md): из строки или столбца таблицы можно вычесть (или прибавить) одно и то же число – лучший план от этого не меняется. Клетки с нулём в новой таблице называются **честными маршрутами**. Потенциал – это сколько всего вычли из строки или столбца.

---

## 1. Наш метод

### Шаг 1. Вычитаем минимумы

Минимумы строк: A1 – 2, A2 – 3, A3 – 2.

```
          B1   B2   B3
A1         1    0    0
A2         2    1    0
A3         4    2    0
```

Минимумы столбцов: B1 – 1, B2 – 0, B3 – 0. Вычитаем 1 из столбца B1:

```
          B1   B2   B3
A1         0    0    0
A2         1    1    0
A3         3    2    0
```

### Шаг 2. Развозим по нулям

- **A1 → B1: 3.** Склад A1 пуст. B1 нужно ещё 1.
- **A2 → B3: 4.** У A2 осталось 1. B3 заполнен.

Затор. У A2 (остался 1) и у A3 (осталось 2) единственный ноль – B3, а он полон. Переставить тоже некого: в B3 везёт только сам A2, и других нулей у него нет.

### Шаг 3. Создаём новый ноль – сразу для всех застрявших

Застрявшая группа: склады **A2, A3** и магазин **B3** (куда они упираются).

Ищем самую дешёвую клетку, ведущую из группы наружу, то есть из строк A2, A3 в столбцы B1, B2: это A2→B1 = 1 и A2→B2 = 1. Значит, сдвиг равен **1**.

- Из строк A2 и A3 вычитаем 1.
- К столбцу B3 прибавляем 1, чтобы внутри группы ничего не поменялось.

```
          B1   B2   B3
A1         0    0    1
A2         0    0    0      ← два новых нуля
A3         2    1    0
```

Клетка A1→B3 стала 1, но по ней ничего не возят – это не мешает.

### Шаг 4. Снова развозим по нулям

- **A2 → B1: 1.** A2 пуст, B1 заполнен.
- У A3 осталось 2, его ноль – B3, а B3 полон. Но в B3 везёт A2, а у A2 теперь есть ноль в B2, где нужно ещё 2. **Перестановка:** A2 везёт 2 в B2 вместо B3, освободившееся место в B3 занимает A3.

Итоговый план:

```
          B1   B2   B3
A1         3    0    0
A2         1    2    2
A3         0    0    2
```

Стоимость: 3·3 + 5·1 + 4·2 + 3·2 + 2·2 = **32**.

**Итог: один сдвиг потенциалов.**

## 2. Метод потенциалов

Идёт с другой стороны: сначала полный (но, возможно, плохой) план, потом исправления.

### Шаг 1. Начальный план методом минимального элемента

Берём клетки от дешёвых к дорогим и везём, сколько можно:

| Клетка | Цена | Везём | Что осталось |
|---|---|---|---|
| A1→B2 | 2 | 2 | у A1 – 1, B2 заполнен |
| A1→B3 | 2 | 1 | A1 пуст, B3 нужно 3 |
| A3→B3 | 2 | 2 | A3 пуст, B3 нужно 1 |
| A2→B3 | 3 | 1 | у A2 – 4, B3 заполнен |
| A2→B1 | 5 | 4 | всё развезено |

```
          B1   B2   B3
A1         0    2    1
A2         4    0    1
A3         0    0    2
```

Стоимость: 4 + 2 + 20 + 3 + 4 = **33**. Это не оптимум (оптимум – 32), но метод пока об этом не знает.

### Шаг 2. Потенциалы от плана

Подбираем потенциалы так, чтобы в **занятых** клетках получились нули: цена = потенциал строки + потенциал столбца. Начинаем с A1 = 0:

- A1→B2: 2 = 0 + B2, значит **B2 = 2**;
- A1→B3: 2 = 0 + B3, значит **B3 = 2**;
- A3→B3: 2 = A3 + 2, значит **A3 = 0**;
- A2→B3: 3 = A2 + 2, значит **A2 = 1**;
- A2→B1: 5 = 1 + B1, значит **B1 = 4**.

### Шаг 3. Новая таблица: цена − потенциал строки − потенциал столбца

```
          B1   B2   B3
A1        −1    0    0
A2         0    1    0
A3         2    2    0
```

В клетке A1→B1 стоит **−1**. Минус означает, что если пустить товар по этому маршруту, каждая единица сэкономит 1. План не оптимален.

### Шаг 4. Цикл пересчёта

Хотим везти в A1→B1. Но если просто добавить туда товар, A1 отдаст больше, чем у него есть, а B1 получит больше, чем нужно. Поэтому строим цикл по занятым клеткам и чередуем «+» и «−», чтобы суммы в строках и столбцах не изменились:

```
A1→B1 (+)  →  A1→B3 (−)  →  A2→B3 (+)  →  A2→B1 (−)
```

Сколько перекладываем: минимум по клеткам с «−»: A1→B3 = 1, A2→B1 = 4, значит **1**.

```
          B1   B2   B3
A1         1    2    0
A2         3    0    2
A3         0    0    2
```

Стоимость: 3 + 4 + 15 + 6 + 4 = **32**. Сэкономили ровно 1 × 1.

### Шаг 5. Снова потенциалы и проверка

Новые потенциалы: A1 = 0, A2 = 2, A3 = 1, B1 = 3, B2 = 2, B3 = 1.

```
          B1   B2   B3
A1         0    0    1
A2         0    0    0
A3         2    1    0
```

Минусов нет – план оптимален. **Итог: одна итерация (один цикл).**

Обратите внимание: таблица получилась **точно такой же**, как в конце нашего метода. Оба метода приходят в одну точку – «всё развезено, минусов нет», – только с разных сторон. Планы при этом немного разные: у задачи два оптимальных плана, оба стоят 32.

## 3. Венгерский метод

Венгерский метод – это **та же идея, что у нас**: вычитаем, возим по нулям, при заторе создаём новый ноль. Наш метод – его ускоренный вариант (в литературе оба называют прямо-двойственными). Разница одна: классический венгерский метод обрабатывает **склады по одному**, а наш – **все сразу**.

Начало то же самое:

```
          B1   B2   B3
A1         0    0    0
A2         1    1    0
A3         3    2    0
```

### Склад A1

**A1 → B1: 3.** A1 пуст.

### Склад A2

**A2 → B3: 4.** У A2 остался 1, но других нулей у него нет. Затор.

Застрявшая группа – **только A2** и B3 (A3 в группу не входит: сейчас занимаемся только складом A2). Сдвиг – 1.

```
          B1   B2   B3
A1         0    0    1
A2         0    0    0
A3         3    2    1      ← A3→B3 был нулём, а стал 1!
```

Так как к столбцу B3 прибавили 1, а строку A3 не трогали, A3 **потерял** свой ноль.

**A2 → B1: 1.** A2 пуст.

### Склад A3

У A3 вообще нет нулей. Затор. Группа – только A3. Наименьшее число в строке A3 – 1. Вычитаем:

```
          B1   B2   B3
A1         0    0    1
A2         0    0    0
A3         2    1    0      ← ноль вернулся
```

Перестановка, как у нас: A2 везёт 2 в B2 вместо B3, A3 занимает место в B3. План и стоимость (**32**) – те же, что у нашего метода.

**Итог: два сдвига.** Второй сдвиг лишь вернул ноль, который испортил первый. Наш метод сдвинул A2 и A3 вместе и обошёлся одним сдвигом.

## 4. Сравнение

| | Метод потенциалов | Венгерский метод | Наш метод |
|---|---|---|---|
| С чего начинает | полный план (может быть плохим) | таблица без минусов, плана нет | таблица без минусов, плана нет |
| Что исправляет | убирает минусы из таблицы | достраивает план | достраивает план |
| Единица работы | один цикл пересчёта = одна клетка | один склад за раз | все склады сразу |
| На примере | 1 цикл | 2 сдвига | 1 сдвиг |
| **На конкурсном тесте 1000×1000** | 10–16 тысяч циклов, **1,2–1,9 с** | ~3 900 поисков пути, **2,3 с** | 19 сдвигов, **0,06 с** |

На маленьком примере разница незаметна. Но на тысяче складов:

- **Метод потенциалов** делает тысячи мелких исправлений по одной клетке. Каждое – обход цикла и пересчёт потенциалов у сотен строк, всё на Python, шаг за шагом.
- **Венгерский метод** обрабатывает склады по одному. Сдвиги для разных складов мешают друг другу (как ноль A3 в примере), и работы становится больше.
- **Наш метод** обрабатывает все застрявшие склады одним сдвигом. Один сдвиг – одна операция NumPy сразу над тысячами клеток. Таких сдвигов всего 19.

Все три метода точные, на конкурсном тесте все дали 1 415 114. Разница только в скорости.
